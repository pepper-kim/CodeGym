# Repository instructions

## Database learning

For any database-learning task or change under `database/`, read `database/README.md` before planning or editing. If the task concerns a specific database and a matching `database/<product>/README.md` exists, read that document as well.

Treat `database/README.md` as the source of truth for the shared long-term goal, comparison framework, source hierarchy, and learning and pass procedure. Treat each product README as the source of truth for that product's learning scope, curriculum, progress, completion criteria, and application of the shared evidence rules.

Do not change agreed goals or curriculum structure without explicit user agreement. After agreement, update the appropriate source-of-truth README to reflect it.
