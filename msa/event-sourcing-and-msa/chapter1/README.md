# 도메인 주도 설계
모델은 단순하게 표현한 실제 세계다. 모델을 표현할 때는 해결 해야 하는 문제를 바라보는 다양한 관심사 중 하나를 선택해서 문제를 설명하는데 꼭 필요한 것만 선택 해야 함. 그렇지 않으면 모델이 여러 관심사를 담아 한 없이 복잡해지게 된다. 관심사에 따라 문제를 정의하는 모델이 달라져야 한다. 자신이 관심 있는 속성만 보는 것이 모델의 응집도를 높이고 모델관 결합도를 낮추는 방향이다.
