# CSS
## Properties
### position
https://developer.mozilla.org/en-US/docs/Web/CSS/position
#### Values
##### absolute
- 일반적인 문서 흐름에서 제거되고 page layout에서 공간을 할당 받지 못함.
- element는 자신과 가장 가까운 조상 혹은 containing block에 상대적으로 배치됨.

##### fixed
- 일반적인 문서 흐름에서 제거되고 page layout에서 공간을 할당 받지 못함.
- element는 초기의 containing block에, visual media에선 viewport, 상대적으로 배치됨.
