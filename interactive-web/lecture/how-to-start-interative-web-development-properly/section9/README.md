# Window
## Instance properties
### scrollY
- `document`가 수직 스크롤이 얼마나 됐는지 나타내는 값

### innerHeight
- window의 interior height를 나타냄.
- window의 layout viewport의 높이를 가져옴.

# Layout viewport란?
브라우저가 웹페이지를 그리는 viewport를 Layout viewport라고 함. 현재 볼 수 있는 것들을 나타냄. 그에 반해 Visual viewport는 Layout viewport 내에서 사용자의 디바이스로 볼 수 있는 부분을 나타냄. Layout viewport에서 zoom을 하면 Visual viewport가 됨.
